# Hannah Scarbrough's dissertation GitHub resources

The 'Analysis' folder contains the analysis materials. There is a folder to 
set up the data and subset the Meta-Analyses (dissertation-test). There is also a raw data 
folder.

The 'lit review visuals' has the code used to build the visuals in the literature 
review.

The 'Literature Searching' folder contains the Python code used for scraping and
reporting the Google search results in Python.
